# Auth email runbook

Chess ML Coach sends every Supabase Auth email through the `send-email` Edge Function
(`supabase/functions/send-email`) and Brevo's HTTPS transactional API. That covers account
confirmation and password reset, plus email change, invite, and reauthentication. The browser
never sees any provider or hook secret. The same setup is used by Portfolio-Builder.

Supabase's built-in email sender is for testing only: it allows about two messages per hour for
the whole project, and returns `over_email_send_rate_limit` beyond that.

## How it works

1. A user signs up or asks for a password reset. Supabase Auth creates the token and calls the
   **Send Email Hook** with a Standard Webhooks-signed payload.
2. `send-email` verifies the signature and rejects anything unsigned with `401`. It builds the
   branded message: the link is `SUPABASE_URL/auth/v1/verify?token=…&type=…&redirect_to=…`, and
   all content is HTML-escaped. It then posts the message to Brevo.
3. The function returns `200` only after Brevo accepts every message, so Supabase reports a
   failure to the user instead of silently dropping the email.

## Secrets

Set these as Supabase **Edge Function secrets** (Dashboard → Edge Functions → Secrets, or
`supabase secrets set`), never in the repo or on Render:

| Secret | Value |
| --- | --- |
| `BREVO_API_KEY` | Brevo → SMTP & API → API Keys (a v3 API key, not the SMTP password) |
| `BREVO_SENDER_EMAIL` | A sender verified in Brevo (Senders, Domains) |
| `BREVO_SENDER_NAME` | `Chess ML Coach` |
| `SEND_EMAIL_HOOK_SECRET` | Generated by Supabase when the hook is created (step 3); starts with `v1,whsec_` |

`SUPABASE_URL` is provided to Edge Functions automatically. The same Brevo account and verified
sender can be shared with Portfolio-Builder.

## Deploy

The Supabase CLI changes over time. Check its help output before running commands
(`npx supabase functions deploy --help`, `npx supabase secrets set --help`).

1. **Log in and deploy the function**, confirming the project ref (`srzpznhyzwjpukzuutax`):

   ```bash
   npx supabase login
   npx supabase functions deploy send-email --project-ref srzpznhyzwjpukzuutax --no-verify-jwt
   ```

   `--no-verify-jwt` is required. Supabase Auth, not a user, calls the function, and the
   function instead rejects every request without a valid webhook signature.

2. **Set the Brevo secrets** without echoing them. Put them in a temporary file outside the repo
   and delete it afterwards:

   ```bash
   tmp=$(mktemp -d) && chmod 700 "$tmp"
   # write BREVO_API_KEY=…, BREVO_SENDER_EMAIL=…, BREVO_SENDER_NAME=Chess ML Coach to "$tmp/email.env"
   npx supabase secrets set --env-file "$tmp/email.env" --project-ref srzpznhyzwjpukzuutax
   rm -rf "$tmp"
   ```

3. **Enable the hook**:
   1. Go to Dashboard → Authentication → Hooks → **Send Email Hook** and choose type HTTPS.
   2. Set the URL to `https://srzpznhyzwjpukzuutax.supabase.co/functions/v1/send-email`.
   3. Click *Generate secret* and store it as the `SEND_EMAIL_HOOK_SECRET` function secret
      (same method as step 2).
   4. Enable the hook.

4. **Raise the email rate limit**: Dashboard → Authentication → Rate Limits → *Emails sent per
   hour*, for example `100`. The limit applies before the hook runs, and turning on the hook does
   not raise it on its own.

5. **Password settings**: Dashboard → Authentication → Sign In / Providers → Email.
   - Keep **Confirm email** on.
   - Set **Minimum password length** to at least `8`, matching the app.
   - Consider enabling leaked-password protection.

## Verify

1. On the live site, create an account with a fresh address, for example a Gmail
   `+alias`. The confirmation email should come from `BREVO_SENDER_NAME` and link back to the
   site signed in.
2. Sign out, choose **Forgot password?**, open the reset email, set a new password, then sign in
   with it.
3. Check the function logs (Dashboard → Edge Functions → send-email → Logs). They should show
   `200` responses, and a request without a signature should get `401`.

Record only outcomes, never passwords, tokens, API keys, or complete verification URLs.

## Rollback

Disable the Send Email Hook. Supabase falls back to its built-in sender, rate-limited as above,
or to custom SMTP if configured.
